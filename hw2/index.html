From Wikipedia, the free encyclopedia

"Rust" redirects here. For the video game, see Rust (video game). For the fungus, see Rust (fungus).

Rust is a multi-paradigm, general-purpose programming language that emphasizes performance, type safety, and concurrency. It enforces memory safety—meaning that all references point to valid memory—without requiring the use of a garbage collector. To simultaneously ensure memory safety and prevent data races, its "borrow checker" tracks the object lifetime of all references in a program during compilation.

Software developer Graydon Hoare created Rust as a personal project while working at Mozilla Research in 2006. Mozilla officially sponsored the project in 2009. In the years following its first stable release in 2015, Rust has been adopted by major technology companies including Amazon, Discord, Dropbox, Google, Meta, and Microsoft.

Rust is noted for its rapid growth and widespread popularity among developers. It has been voted the "most loved programming language" in the Stack Overflow Developer Survey every year from 2016 to 2023. The language has gained significant traction in system programming, WebAssembly, and backend web development.

In 2022, Rust became the first language other than C and assembly to be supported in the development of the Linux kernel. Major tech companies and government agencies (such as CISA and the NSA) have increasingly advocated for utilizing Rust for critical infrastructure due to its security benefits over memory-unsafe languages like C and C++.

The Rust Foundation, an independent non-profit organization, was established in 2021 by major tech companies to support the maintenance and development of the language. The organization manages the trademarks, infrastructure, and core community ecosystem of the Rust programming language.
